# HALVETH Bio-Universe

Use `node scripts/bio-universe.mjs check` from the plugin root before relying on the catalog and bundled synthetic result. Use `list`, `show <lab-id>`, `relations` or `result` for compact facts. Use `serve` for the local visual research center. The server binds to `127.0.0.1` and serves only bundled, data-free material.

Catalog records identify functions and source visibility; they do not install the original labs. The bundled result was generated from exact locally bound NOVA, Open Organism and adapter source bytes; it is a synthetic model reference event, not biology. `LOCAL_TESTED_LEGACY` marks the old adapter's known trust gaps. `CANDIDATE` and `HOLD` edges are not working integrations. Keep personal DNA, biometrics, secrets, private paths and run artifacts out of this package. Open source publication of a source lab requires a separate path/version rights check.

Rachel Auftragssystem and HALVETH Perspektivkorridor are optional neighboring plugins. This package does not update or invoke them automatically.
